# MyRoomWatch landing page

Production-ready, responsive landing page (Harbour direction).

Files:
- index.html — the page (semantic HTML, no JS required)
- styles.css — all styles + mobile breakpoint at 900px

Notes:
- Fonts load from Google Fonts (Manrope + Public Sans). Self-host them if you prefer.
- Brand tokens are CSS variables at the top of styles.css (--ink, --accent, …) — retheme by editing those.
- CTA links point to #pricing / # placeholders; wire them to your signup URL.
